# Work Playbooks

You have a task at work and you're not sure where to start. Each playbook takes one real task, like "test this new API endpoint by Friday", and walks it from the first hour to the final report. You get a plan you can copy, scripts that run against **your own app**, and a report template.

!!! info "How to use a playbook"
    1. Find the task that looks like yours.
    2. Download its kit (one ZIP per playbook).
    3. Follow the steps with your own app's address and login.
    4. Copy the plan and the report into your ticket.

    The pages show real runs against public demo APIs, so you can see what each script prints before you use it at work.
