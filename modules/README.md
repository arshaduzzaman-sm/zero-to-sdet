# modules

Runnable code for every topic: templates, examples, exercises, solutions and tests.

This folder mirrors `docs/`. A topic at `docs/core-automation/api-testing/` keeps its code at
`modules/core_automation/api_testing/` (Python package names use underscores).

Each topic folder has:

```text
templates/   ready-to-copy files, each starting with the credit line
examples/    small runnable examples used in the lessons
exercises/   "Try it yourself" starting points
solutions/   answers to the exercises
tests/       tests that prove every template and example works
```

Topic folders are added when their lessons are written.
